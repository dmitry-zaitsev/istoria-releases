# istoria-releases

Public release-artifact host for [`istoria`](https://github.com/dmitry-zaitsev/istoria).

CI in the (private) source repo publishes signed `.tar.gz` bundles + `SHA256SUMS` here on tag push so Homebrew can fetch them without auth.

Install via the tap:

```sh
brew install dmitry-zaitsev/tap/istoria
```

Tap repo: <https://github.com/dmitry-zaitsev/homebrew-tap>
